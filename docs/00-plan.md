## 2. 关键技术决策

### 2.1 为什么是 SDL3 + OpenGL 3.3 Core

| 选项 | 评价 |
|------|------|
| **SDL3 + OpenGL 3.3 Core** | ✅ 跨平台，3.3 是兼容性最好的现代基线；D3D8 的固定管线映射清晰 |
| D3D11/Vulkan | 过重，重制不需要 |
| 保留 D3D8 | ✗ 不可迁移 |

**D3D8 固定管线 → GL 3.3 的映射关系**（重制时逐一对照）：

| D3D8 (TH07) | OpenGL 3.3 |
|-------------|-----------|
| `SetTransform(WORLD/VIEW/PROJ)` | uniform mat4 x3 |
| `D3DXMatrixOrthoOffCenterLH` | 正交投影矩阵 |
| `SetRenderState(ZENABLE/ALPHABLEND)` | 深度测试 + blend 状态 |
| `DrawPrimitiveUP` | VBO + `glDrawArrays` |
| `SetTextureStageState` | 采样器 + 着色器 |
| `D3DXCreateTextureFromFileInMemoryEx` | stb_image / 自定义 ANM 解码 + `glTexImage2D` |

### 2.2 为什么用 Lua 替代 ECL

- ECL 是**栈式 + 时间轴协程**的字节码，天然适合翻译成带 `coroutine` 的 Lua
- 可保留 `time` 语义：`fork()` / `wait(n)` 映射到协程 `coroutine.yield`
- 便于 MOD 社区改造关卡
- **关键约束**：必须能 1:1 无损还原原版行为，因此需要「Lua → ECL」逆向也可能的双向工具（至少保留原始 offset 映射，见 §5）

### Phase 2 — ECL 虚拟机逆向（核心，最高优先级）

这是用户明确要求的重点。ECL 本质是一个**小虚拟机**，要把「壳」完全剥开。

| # | 任务 | 说明 | 验收标准 |
|---|------|------|----------|
| 2.1 | 定位 ECL 解释器 | 找 `RunEcl` / 指令分发大 `switch` | 函数已命名并入文档 |
| 2.2 | 还原 opcode 分发表 | 161 项 × (handler 指针, 参数格式) | 生成 `docs/02-ecl-instructions.md` |
| 2.3 | 逐条语义 | 每条:输入/输出/副作用/时间消耗 | **161/161 有文档** |
| 2.4 | 参数解码 | `param_mask` + 格式串 → 具体参数 | 与 `thecl` 导出 100% 对齐 |
| 2.5 | 跳转/调用语义 | `call`、`jump`、`ret`、条件分支 | 控制流图可重建 |
| 2.6 | 时间轴语义 | `time` 推进、`wait`、协程唤醒 | 单帧步进可复现 |
| 2.7 | 变量系统 | 局部/全局变量、偏移寻址 | 变量访问正确 |

**方法论（关键）**：
> 不要「读代码猜语义」。用**差分执行**：
> 1. 把 ECL 转成可执行模型（本仓库 Python 实现）
> 2. 用原版游戏 + 录像跑出「(帧, 变量值)」轨迹
> 3. 对比我们的模型输出，不一致处就是语义理解错误
>
> 这是唯一能保证 161 条全对的方法。

## 5. 工程约定

### 5.1 Git

- 二进制（`th07.exe` / `*.dat` / `*.ecl` / `*.anm` / Ghidra 工程）**全部 gitignore**
- `thtk/` 是独立 clone（有自己的 origin），通过 `.git/info/exclude` 本地忽略，
  **不触碰其远端**
- 所有逆向结论必须**可复现**：文档里写清用哪个工具、哪条命令得出的

### 5.2 证据等级

文档中的每条结论标注可信度：

| 标记 | 含义 |
|------|------|
| **[已验证]** | 有脚本/数据 100% 校验通过 |
| **[反汇编]** | 来自 Ghidra 反编译，与数据一致 |
| **[推测]** | 未经充分验证，需后续确认 |
| **[待查]** | 未开始 |

### 5.3 代码规范

- Python 工具：零第三方依赖（便于在任何机器跑），`--help` 完整
- 每个工具都能独立作为 CLI 使用，也可被 import
- 关键算法注释里写清**为什么**这么实现（尤其与 thtk 行为不同处）

## 6. 已知风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| ECL 语义靠猜，某条理解错 | 关卡行为偏差，难定位 | 差分执行 + 录像轨迹对比 |
| 渲染是 D3D8 固定管线，矩阵约定不同 | 画面错位 | 数学层单独抽离并单元测试 |
| 原版有未文档化的硬件依赖（如 Vs/Ps 版本） | 重制无法完全一致 | 逐阶段降级策略 |
| thtk 导出结果有已知缺陷 | 对照基准不可靠 | 已定位，改用本仓库解析器 |
| 变量寻址偏移在 TH07 有特殊规则 | Lua 转译错位 | 优先还原变量系统（Phase 2.7） |
