## 2. 分组观察

### 2.1 按精灵编号

| 精灵 | 数量 | 时长范围 | 缩放范围 |
|------|------|---------|---------|
| **0x4a1** | 7 | 140–300 | 200–360 |
| **0x4a2** | 2 | 260–340 | 310–390 |
| **0x4a3** | 3 | 160–300 | 260–420 |

**精灵 0x4a1 对应 7 个 Bomb，0x4a2 只有 2 个。**

### 2.2 这个分组意味着什么（**未确认**）

可能的解释：
- (a) `0x4a1/0x4a2/0x4a3` 是**三种爆炸特效外观**，被多个 Bomb 复用
- (b) 分组对应**自机角色**（但 7:2:3 的分布不像三方平均分）
- (c) 分组对应**Bomb 类型**（扩散/集中/持续）

**我没有足够证据确定。** 上面的别名 `a/b/c` 只是按精灵分组的中性代号，
**不代表任何已确认的语义**。

### 2.3 为什么 7:2:3 不像角色分布

TH07 有 3 个自机（`ply00/01/02`），每个有 2 种攻击方式 = 6 种组合。
如果每组合 1 个 Bomb，应有 6 个，但实际有 12 个。

**说明每个组合有 2 个 Bomb 变体**（例如"移动中"和"原地"），
或 Bomb 外观随某些状态变化。

## 3. 已精读的两个（参考实现）

### 3.1 bomb_a1（`FUN_00408710`）

```
总时长 140 帧
第 8–79 帧，每 6 帧生成一个（index 0–11）
角度 = index * 2π/8 - π/2       （8 等分，从正上起）
起始位置 = 释放瞬间（所有弹共享）
初速 15.0，减速 0.4/帧，< -10.0 爆开
x >= 192 时镜像（dir = -index）
```

**特征：规整的八方向星形。**

### 3.2 bomb_a2（`FUN_004091b0`）

```
总时长 300 帧
第 60–179 帧，每 16 帧生成一个（index 0–7）
角度 = rand() * 2π - π          （随机）
起始位置 = 每弹生成时的玩家位置
初速 8.0
```

**特征：不规则散落。**

## 4. 重制版的现实建议

### 4.1 先做两个参考实现

`bomb_a1` 和 `bomb_a2` 的几何已经完整解出，
足以覆盖"规则散射"和"随机散射"两种模式。
**建议先把这两个做对**，作为 Bomb 系统的基准。

### 4.2 其余 10 个的快速路径

| 情况 | 处理 |
|------|------|
| 如果只是弹幕数量/时长不同 | 改参数即可 |
| 如果有新的几何模式 | 需要精读对应函数 |

**判定方法**：对比函数体的结构（循环嵌套、角度公式）。
结构相同 → 只改参数；结构不同 → 需精读。

### 4.3 位置正确性检查清单

无论哪个 Bomb，都必须：

```lua
pos.x = pos.x + screen_offset_x    -- +32
pos.y = pos.y + screen_offset_y    -- +16
pos.z = 0                           -- 强制归零
```

**漏掉任一项都会导致整体错位或被遮挡。**
