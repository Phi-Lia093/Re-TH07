# 道具收集与速度分档（精读）

> 来源：主更新循环中的道具数量分档控制（`param_1 + 0x962c` 为帧计数）。
> 分档阈值与频率为实测；道具语义关联部分标注了推断程度。

---

## 1. 道具速度分档（**关键机制**）

屏幕上的道具数量影响**道具的移动频率**：

```c
frame_counter++;                       // +0x962c，每帧递增

if ((item_count > 0x13f && frame % 3 == 0) ||
    (item_count < 0x140 && item_count > 0xdf && frame % 4 == 0) ||
    (item_count < 0xe0 && item_count > 0x7f && frame % 5 == 0)) {
    flag = 1;
    return 3;                          // 本帧跳过部分更新
}

if (item_count < 0x80)
    frame_counter = 0;                 // 道具少时复位
```

### 1.1 分档表

| 道具数量 | 阈值（十六进制） | 移动频率 |
|---------|----------------|---------|
| **> 319** | `> 0x13f` | 每 **3** 帧 |
| **224 ~ 319** | `0xe0..0x13f` | 每 **4** 帧 |
| **128 ~ 223** | `0x80..0xdf` | 每 **5** 帧 |
| **< 128** | `< 0x80` | 全速（每帧） |

### 1.2 这是性能保护

道具多时**降低道具更新频率**，避免 1024 个道具同时计算导致卡顿。

**副作用**：道具越多，收集越慢 —— 玩家会感觉道具"粘在"屏幕上。

### 1.3 重制版的处理

现代化重制版**不必保留这个分档**（性能不再是瓶颈），
但要注意：

| 保留分档 | 去掉分档 |
|---------|---------|
| 与原作手感一致 | 收集更快，可能改变平衡 |
| 高道具量时视觉更"粘" | 高道具量时更流畅 |

**建议**：作为可选设置项，默认与原作一致。

## 2. 道具掉落场景

TH07 有多种掉落触发，条件各不相同：

| 函数 | 触发条件 | 掉落数 |
|------|---------|--------|
| `enemy_drop_on_kill` | 敌人被击破 | Easy..Hard = 4，Lunatic = 2 |
| `item_drop_area_check` | 敌人死在玩家 Y ±64 内 | Easy=10 / Normal=18 / Hard+=25 |
| `item_drop_radius_180` | 敌人在玩家 180px 内（Hard 128px） | 按难度 |

### 2.1 enemy_drop_on_kill 的细节

```c
// 按敌人类型（+0xbf8）选择道具种类
switch (enemy->type) {
case 6:   spawn kind 6, sub 0xf;  break;
case 0xf: spawn kind 6, sub 0xf;  break;
case 2:   spawn kind 6, sub 0xf;  break;
}

// 掉落数量
count = (difficulty < 3) ? 4 : 2;

// 速度：敌人速度的 1.1 / 0.7 / 0.85 倍
item[0].speed = enemy->speed * 1.1;
item[1].speed = enemy->speed * 0.7;
item[2].speed = enemy->speed * 0.85;

// 角度：以敌人朝向 ± π/6、π/3 展开
```

### 2.2 难度对角度的影响

```c
if (difficulty < 3) {          // Easy/Normal/Hard
    spread = 4;                // 4 个方向
    angle_step = PI / 6;       // 30°
} else {                       // Lunatic
    spread = 2;                // 2 个方向
    angle_step = PI / 2;       // 90°
}
```

**Lunatic 掉得少但角度更分散。**

### 2.3 特殊标志 0x2000

```c
if (...)
    item->flags = 0x2000;      // 或 0x2002
```

`0x2000` 标志的含义**未确认**。
以下均为猜测，不应采信：可能是"自动吸向玩家"、"不可收集"或其他。
需要追踪该标志的读者才能确定。

## 3. 道具数量上限

```c
if (g_item_count >= 0x400) return;    // 1024
```

超过 1024 个道具时**不再生成**。

---

## 4. 重制版照抄要点

### 4.1 必须保留

| 特性 | 原因 |
|------|------|
| 三种掉落场景的分工 | 影响资源曲线 |
| 难度掉落数（10/18/25、4/2） | 直接平衡 |
| 速度倍率 1.1/0.7/0.85 | 道具散开的观感 |
| 1024 上限 | 防止极端情况 |

### 4.2 可选

| 特性 | 建议 |
|------|------|
| 速度分档（3/4/5 帧） | 做成开关，默认保留 |
| 0x2000 标志 | 需先确认语义 |
