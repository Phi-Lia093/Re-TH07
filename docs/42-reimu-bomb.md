## 1. 初始化（第 0 帧）

```c
if (frames != last_frames && frames == 0) {
    FUN_0042868d(0x4a1, "...");           // 播放音效

    total_frames = 0x8c;                  // 140 帧总时长
    player_scale = 200;                   // 玩家缩放基准
    scale_frac   = 0;
    scale_timer  = -999;

    screen_fade_update();

    for (i = 0; i < 0x20; i++)            // 清空 32 个特效槽
        effect_slot[i] = 0;

    reset_objects();

    // 生成红色圆形特效
    obj_spawn_at(0xc, &player->pos, 1, 0xff4040ff);
    // 位置偏移与参数
    FUN_004418b0(&player->pos, 32.0, 8.0, 0x10, 6);

    // 记录起始位置
    bomb_start_x = player->x;
    bomb_start_y = player->y;
    bomb_start_z = player->z;

    bullet_rank_scale(0.4f);              // 弹幕等级缩放
}
```

### 1.1 关键参数

| 参数 | 值 |
|------|-----|
| **总时长** | **140 帧**（`0x8c`） |
| 玩家缩放 | `200` |
| 特效槽数 | 32 |
| 起始特效类型 | `0xc` |
| 特效颜色 | `0xff4040ff`（红） |
| 位置偏移 | `(32.0, 8.0)` |
| 弹幕等级缩放 | `0.4` |

## 2. 弹幕生成（第 8-79 帧）

```c
if (frames != last_frames && frames > 7 && frames < 0x50 && frames % 6 == 0) {

    index = (frames - 8) / 6;             // 0, 1, 2, ...

    slot = &effect_slot[index * 0x1428];
    slot->active    = 1;
    slot->speed     = 15.0f;              // 0x41700000
    slot->pos.x     = player->x;          // ← 玩家当前位置
    slot->pos.y     = player->y;
    slot->pos.z     = player->z;

    // 方向：8 等分圆，从 -π/2 起
    dir = index;
    if (bomb_start_x >= 192.0)            // 玩家在右半边 → 反向
        dir = -index;
    angle = (dir * 2π) / 8.0 - π/2.0;
    slot->angle = angle_normalize(angle);

    slot->state = 0;

    // 绑定 4 个动画脚本
    for (k = 0; k < 4; k++)
        anm_set_sprite_script(slot + k, 0x485 + k);

    snd_request(0xd, 0);
}
```

### 2.1 生成时机

| 帧 | 动作 |
|----|------|
| 0 | 初始化 |
| 8, 14, 20, 26, 32, 38, 44, 50, ..., 74 | **每 6 帧生成一个** |
| 8-79 | 生成窗口 |

实测生成帧：`[8,14,20,26,32,38,44,50,56,62,68,74]`，共 **12 个**，
`index` 范围 0–11。

### 2.1.1 但更新循环只处理 8 个（**重要**）

```c
// 更新循环
local_14 = param_1 + 0x16a4c;
for (local_10 = 0; local_10 < 8; local_10++) {
    ...
    local_14 += 0x50a;          // 0x50a * 4 = 0x1428
}
```

**只遍历 index 0–7 的 8 个槽位。**

而生成时 `index` 可达 11。**index 8–11 的槽位被写入，但逐帧更新与绘制都不会碰它们。**

这是一个**真实的结构限制**（或潜在 bug）。可能的情况：
- (a) 生成窗口实际上到不了 12 个（受其他条件限制）
- (b) index 8-11 确实被创建但不可见 —— 原作的无声浪费
- (c) 其他函数处理了超出部分（未找到）

**重制版建议：只实现 8 个槽位**，与更新循环一致。

### 2.2 方向分布（关键）

```
angle = (index * 2π/8) - π/2
```

| index | 角度 |
|-------|------|
| 0 | **-90°（正上）** |
| 1 | -45° |
| 2 | 0°（正右） |
| 3 | 45° |
| 4 | 90°（正下） |
| 5 | 135° |
| 6 | 180°（正左） |
| 7 | 225° |

**8 等分圆，从正上方开始顺时针。**

### 2.3 左右镜像

```c
if (bomb_start_x >= 192.0)    // 屏幕中线（384/2）
    dir = -index;              // 反向
```

**玩家在右半边释放时，弹幕顺时针方向相反** ——
这是 TH07 的对称性设计。

> **注意**：`192.0` 是**逻辑坐标**的中线（游戏区宽 384 的一半）。

## 3. 逐帧更新（每帧）

```c
player->state = 3;                       // ← Bomb 期间状态为 3

for (i = 0; i < 8; i++) {
    slot = &effect_slot[i];
    if (slot->active && slot->state == 1) {

        // 1. 速度衰减
        slot->speed -= g_slow_factor * 0.4;

        // 2. 位置 = 极坐标 + 起始位置
        slot->pos.x = cos(slot->angle) * slot->speed + bomb_start_x;
        slot->pos.y = sin(slot->angle) * slot->speed + bomb_start_y;

        // 3. 速度耗尽 → 爆开
        if (slot->speed < -10.0) {
            obj_spawn(6, &slot->pos, 8, 0xffffffff);       // 8 个白色粒子
            obj_spawn(0xc, &slot->pos, 1, 0xff4040ff);     // 红色

            slot->state = 2;

            // 4 个动画槽重置
            anm[0x37e] = 1; anm[0x5ca] = 1;
            anm[0x816] = 1; anm[0xa62] = 1;

            // 记录爆开位置
            burst_pos = slot->pos;
            burst_scale[0] = 256.0;      // 0x43800000
            burst_scale[1] = 256.0;
            burst_timer    = 400;

            FUN_004418b0(slot->pos, 64.0, 4.2667, 0x1e, 6);

            slot->vel = 0;               // 停止
            snd_request(0xf, 0);
        }
    }
}
```

### 3.1 弹道参数

| 参数 | 值 |
|------|-----|
| 初速 | **15.0** |
| 减速 | `g_slow_factor * 0.4` 每帧 |
| 爆开阈值 | 速度 < **-10.0** |
| 爆开粒子 | 8 白 + 1 红 |
| 爆开缩放 | 256.0 |
| 爆开计时 | 400 帧 |

### 3.2 飞行距离

```
v(t) = 15 - 0.4t
到达 -10 需要 t = (15+10)/0.4 = 62.5 帧
但总时长只有 140 帧，且生成窗口到 79 帧
```

**每个弹在爆开前飞约 62 帧。**

## 5. 重制版照抄要点

### 5.1 必须精确复刻

| 参数 | 值 | 影响 |
|------|-----|------|
| 总时长 | **140 帧** | Bomb 持续时间 |
| 生成间隔 | **6 帧** | 弹幕密度 |
| 初速 | **15.0** | 扩散范围 |
| 减速 | **0.4/帧** | 飞行动感 |
| 8 等分角 | **`2π/8`，-π/2 起** | 覆盖形状 |
| 左右镜像阈值 | **192.0** | 对称性 |
| 爆开阈值 | **-10.0** | 视觉节奏 |
| 玩家缩放 | **200** | 视觉表现 |

### 5.2 位置正确性（你的核心要求）

**位置公式**：

```lua
-- 每个弹的位置（相对于玩家起始位置）
pos.x = cos(angle) * speed + bomb_start_x
pos.y = sin(angle) * speed + bomb_start_y
```

**关键**：`bomb_start_x/y` 是**释放瞬间的玩家位置**，不是逐帧跟随。
所以弹幕是**从固定点向外扩散**，玩家移动不会拖动弹幕。

### 5.3 容易做错的点

1. **角度从 -π/2 起**（正上方），不是从 0
2. **左半边顺时针，右半边逆时针**
3. **起始位置固定**，不是跟随玩家
4. **减速是 0.4/帧**，不是比例衰减
