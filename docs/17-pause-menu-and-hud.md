> 来源：`ui_pause_menu`（`FUN_00402780`, 334 行）与 `ui_hud_draw`（`FUN_0042b603`）逐段精读。

## 1. 暂停菜单（ui_pause_menu）

### 1.1 布局

暂停菜单是**对象数组**，10 个槽位：

```
base       = param_1
slot_size  = 0x93 (字节)   // 注意：以 undefined1 数组索引
实际 AnmInstance 步长 = 0x24c
```

初始化时一次加载 10 个 ANM 脚本：

```c
for (i = 0; i < 10; i++) {
    slot->script = 0xfe + i;          // 脚本号 0xFE..0x107
    anm_set_script(slot, script_table[0xfe + i]);
}
```

### 1.2 状态机

| state | 含义 | 转出条件 |
|-------|------|---------|
| 0 | **初始化**：加载 10 个脚本，设定难度图标 | 立即 → 1 |
| 1 | **主菜单**（选中"继续游戏"） | ESC → 3；确认 → 2 |
| 2 | 选中项上移 | ESC → 1；确认 → 3 |
| 3 | 选中项下移 | ESC → 2；确认 → 1 |
| 4 | **暂停进入** | — |
| 6 | **返回标题**子菜单 | |
| 8 | 另一子菜单 | |
| 9 | 退出暂停 | |
| 10 | 截图保存 | |

### 1.3 输入位（确认）

```c
DAT_004b9e4c  = 当前输入
DAT_004b9e54  = 上一帧输入
// 边沿检测：各自 & mask 不等即"刚按下"

0x08   = 暂停键
0x10   = ESC
0x20   = 确认（Z）
0x200  = 另一暂停键
0x1001 = 组合键（设置相关）
0x4000 = 截图
```

### 1.4 菜单项视觉状态

```c
for (i = 0; i < 10; i++)
    if (slot[i].flags & 1)              // 该槽有内容
        slot[i].script_id = 2;          // 设为"未选中"变体
```

`+0x1ce`（相对槽）是**视觉状态编号**：`1` = 选中，`2` = 未选中。

### 1.5 颜色常量

Ghidra 把 `0xff303030`（深灰）打印为 `-0x7fcfcfd0`，
把 `0xc0800000`（-4.0f）打印为 `-0x3f800000`。

**陷阱**：Ghidra 对 `0xff......` 开头的 32 位常量会显示为负数，
读取时必须换算：

```python
actual = value & 0xffffffff
```

| Ghidra 显示 | 实际值 | 含义 |
|------------|--------|------|
| `-0x7fcfcfd0` | `0xff303030` | 深灰（未选中文字） |
| `-0x3f800000` | `0xc0800000` | -4.0f（位置哨兵） |
| `-1` | `0xffffffff` | 白色/无 |

## 2. HUD 绘制（ui_hud_draw）

### 2.1 前置设置

```c
anm_flush_batch();

DAT_00575a18 = 0;        // viewport x
DAT_00575a1c = 0;        // viewport y
DAT_00575a20 = 0x280;    // 640
DAT_00575a24 = 0x1e0;    // 480
g_d3d8_device->CaptureStateBlock(...);   // vtable +0xa0
```

### 2.2 调试网格（可关闭）

```c
if ((g_gfx_flags >> 12 & 1) || game_state->paused || g_show_boxes) {
    // 竖线：x = 0, 步长 32，直到 464
    for (y = 0; y < 464; y += 32) draw(obj, x=0, y, scale=0.49);

    // 右侧网格：x = 416..624, y = 16..464
    for (x = 416; x < 624; x += 32)
        for (y = 16; y < 464; y += 32) draw(obj, x, y, scale=0.49);

    // 横线：y = 0 和 y = 464
    for (x = 0; x < 624; x += 128) {
        draw(obj, x, 0,     scale=0.49);
        draw(obj, x, 464.0, scale=0.49);
    }
}
```

**这是调试叠加层，不是 HUD 内容。**

### 2.3 8 个静态 UI 对象

```c
draw(base + 0x000);     // 第一个（普通绘制）
draw_angle(base + 0x24c);
draw(base + 0x498);
draw(base + 0x6e4);
draw(base + 0x930);
draw(base + 0xb7c);
draw(base + 0xdc8);
draw(base + 0x1014);
draw(base + 0x1260);
```

每个对象占 **0x24c 字节**，共 9 个可见对象。

### 2.4 HUD 图标行（**精确坐标，已双向验证**）

```c
const float HUD_X = 496.0;

draw_one(496.0,  64.0,  0.48);   // 0x43f80000, 0x42800000
draw_one(496.0,  96.0,  0.48);   // 0x42c00000
draw_one(496.0, 112.0,  0.48);   // 0x42e00000
draw_one(496.0, 144.0,  0.48);   // 0x43100000
draw_one(496.0, 160.0,  0.48);   // 0x43200000
draw_one(496.0, 176.0,  0.48);   // 0x43300000
draw_one(512.0, 464.0,  0.48);   // 0x44000000, 0x43e80000
```

条件显示（`param_1+4` 的位段控制）：

```c
if ((flags      & 0x3) != 0) draw(496,  96);
if ((flags >> 2 & 0x3) != 0) draw(496, 112);
if ((flags >> 4 & 0x3) != 0) draw(496, 144);
if ((flags >> 6 & 0x3) != 0) draw(496, 160);
if ((flags >> 8 & 0x3) != 0) draw(496, 176);
```

### 2.5 与截图的对照

| 元素 | 反汇编 Y | 截图实测 Y | 差值 |
|------|---------|-----------|------|
| 第 1 行 | 64 | 50–61 | 字形上沿偏移 |
| 第 2 行 | 96 | 66–77 | 同上 |
| 第 3 行 | 112 | 98–100 | 同上 |
| 第 4 行 | 144 | 146–155 | 同上 |
| 第 5 行 | 160 | 162–171 | 同上 |

### 2.6 缩放值

| 常量 | 值 | 用途 |

## 3. 音效请求（FUN_0044c930）

```c
void snd_request(int group, int index)
{
    short v = table[0x49ea8e + index * 8];        // 每项 8 字节
    for (i = 0; i < 5; i++) {
        if (active[i] == index) return;           // 已在播放，跳过
        if (active[i] < 0) break;                 // 找到空槽
    }
    if (i < 5) {
        active[i] = index;
        group->buf[index] = v;
    }
}
```

**5 个同时播放的音效槽位**，重复请求会被合并。
