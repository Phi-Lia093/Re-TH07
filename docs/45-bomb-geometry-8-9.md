# Bomb 几何详解（索引 8 与 9）

> 补全 `docs/44-all-bombs.md` 中索引 8、9 的弹幕几何。
>
> 这两个与索引 0/1 的**结构完全不同** —— 它们用了 96 个槽位。

---

## 1. 槽位数量：一个关键差异

| Bomb | 槽位数 | 更新循环 |
|------|--------|---------|
| 索引 0/1 | **8** | `for (i = 0; i < 8; i++)` |
| **索引 8/9** | **96（0x60）** | `for (i = 0; i < 0x60; i++)` |

**重制版必须按 Bomb 类型分配槽位，不能统一用 8 个。**

---

## 2. 索引 8（`FUN_0040c2e0`，160 帧）

### 2.1 初始化

```c
total_frames = 0xa0;          // 160 帧
player_scale = 0xd2;          // 210

// 记录起始位置
start_x = player->x;
start_y = player->y;
start_z = player->z;

// 清空 96 个槽
for (i = 0; i < 0x60; i++)
    slots[i] = 0;

bullet_rank_scale(0.28f);     // 0x3e8f5c29

// 生成一个追踪载具
carrier = obj_spawn(0x15, player->pos, 1, 0xffffffff);
param_1[0x17e64] = carrier;

snd_request(5, 0);
```

### 2.2 生成（第 60–121 帧）

```c
if (frames > 0x3b) {                          // 第 60 帧后，每帧执行
    budget = 5;                                // ← 每帧重置为 5（已确认）
    for (i = 0; i < 0x60; i++) {
        if (slots[i] == 0) {
            if (frames < 0x79 && budget != 0) {  // 第 121 帧前
                slots[i] = 1;
                anm_set_script(i, (i & 1) + 0x405);   // 交替两种外观

                angle     = rand() * 2π - π;          // 随机方向
                speed     = rand() * 6.0 + 5.5;       // [5.5, 11.5]
                scale     = rand() * 0.1 + 0.1;       // [0.1, 0.2]
                spin      = rand() * 0.0628 - 0.0314; // ±0.0314 rad ≈ ±1.8°

                vx = cos(rand*2π) * 24;               // 初速分量
                ...
                budget--;
            }
        }
    }
}
```

### 2.3 参数汇总

| 参数 | 值 |
|------|-----|
| 总时长 | **160 帧** |
| 生成窗口 | **第 60–121 帧** |
| 每帧上限 | **5 个** |
| 槽位 | **96** |
| 角度 | **随机** `rand*2π - π` |
| 速度 | **`rand*6 + 5.5`** → [5.5, 11.5] |
| 缩放 | `rand*0.1 + 0.1` → [0.1, 0.2] |
| 自旋 | `rand*0.0628 - 0.0314` → ±1.8°/帧 |
| 外观 | `(index & 1) + 0x405`（**两种交替**） |

**特征：从随机方向迸发的密集弹幕。**

**生成速率**：第 60–121 帧共 61 帧 × 每帧最多 5 个 = **理论上限 305 个**，
但受 **96 个槽位**限制，所以实际最多 **96 个**（槽满即停）。

## 3. 索引 9（`FUN_0040ca50`，250 帧）

### 3.1 初始化

```c
total_frames = 0xfa;          // 250 帧
player_scale = 0x122;         // 290

// 96 个槽清零
bullet_rank_scale(0.29f);     // 0x3e947ae1
param_1[0x23f4] = 0.3f;       // 0x3e99999a
param_1[0x23f0] = 0.3f;

carrier = obj_spawn(0x15, player->pos, 1, 0xffffffff);
param_1[0x17e64] = carrier;

snd_request(5, 0);
```

### 3.2 载具跟随（第 0–60 帧）

```c
if (frames >= 0 && frames < 0x3d) {
    carrier->pos = player->pos;      // 载具紧跟玩家
}
```

**载具在前 60 帧跟随玩家。**

### 3.3 生成（第 20–115 帧）

```c
if (frames > 0x13 && frames < 0x74) {         // 第 20–115 帧
    for (i = 0; i < 0x60; i++) {              // 96 个槽
        // 每个槽在特定帧生成
        if (frames == (i % 0x30) * 2 + 0x14) {
            slots[i] = 1;
            anm_set_script(i, (i & 1) + 0x407);      // 两种交替

            // ← 角度：96 等分，从 -π 起
            angle = (i * 2π) / 96.0 - π;

            speed = rand() * 1.0 + 0.5;              // [0.5, 1.5]
            scale = rand() * 0.1 + 0.03;             // [0.03, 0.13]

            spin  = -0.1571;                         // ← -9°/帧，固定

            vx = cos(rand*2π) * 24;                  // 附加初速
            vy = sin(rand*2π) * 24;

            // 位置 = 玩家位置 + 初始偏移
            pos.x = player->x + vx;
            pos.y = player->y + vy;
            pos.z = 0;
        }
    }
}
```

### 3.4 参数汇总

| 参数 | 值 |
|------|-----|
| 总时长 | **250 帧** |
| 生成窗口 | **第 20–115 帧** |
| 生成节奏 | 每个槽在 `(i % 48) * 2 + 20` 帧 |
| 槽位 | **96** |
| 角度 | **`(i * 2π) / 96 - π`**（96 等分） |
| 速度 | **`rand + 0.5`** → [0.5, 1.5] |
| 缩放 | `rand*0.1 + 0.03` → [0.03, 0.13] |
| 自旋 | **−0.1571 rad = −9°/帧**（固定） |
| 载具跟随 | 前 60 帧 |

**特征：围绕玩家螺旋扩散的弹幕。**

### 3.5 角度遍历

| index | 角度 |
|-------|------|
| 0 | **−180°** |
| 1 | −176.25° |
| 24 | −90°（正上） |
| 48 | **0°**（正右） |
| 72 | 90°（正下） |
| 95 | **176.25°** |

**96 个槽覆盖完整 360°，每个间隔 3.75°。**

## 4. 三种 Bomb 结构对照

| 特征 | 索引 0 | 索引 1 | 索引 8 | 索引 9 |
|------|--------|--------|--------|--------|
| 槽位 | 8 | 8 | **96** | **96** |
| 角度 | 8 等分固定 | 随机 | 随机 | **96 等分** |
| 速度 | 固定 15 | 固定 8 | rand[5.5,11.5] | rand[0.5,1.5] |
| 起始位置 | 释放瞬间 | 每弹生成时 | 玩家位置 | **玩家位置+随机** |
| 外形 | 星形 | 散落 | 迸发 | 螺旋 |

**每个 Bomb 的"手感"由这四项共同决定，缺一不可。**

## 6. 索引 2（`FUN_00409dd0`，140 帧，**4 槽**）

### 6.1 槽位数再次不同

```
索引 0/1  →  8 槽
索引 2    →  4 槽
索引 8/9  → 96 槽
```

**这进一步确认：槽位数是每个 Bomb 独立的参数，没有任何统一值。**

### 6.2 实现

```c
// 每帧
handles[0] = get_obj_at(player.pos,  62.0, 448.0, 6);   // 0x42780000, 0x43e00000
handles[1] = get_obj_at(player.pos, 384.0,  62.0, 6);   // 0x43c00000, 0x42780000
handles[2] = get_obj_at(player.pos,  62.0, 448.0, 6);   // 同 [0]
handles[3] = get_obj_at(player.pos, 384.0,  62.0, 6);   // 同 [1]

for (i = 0; i < 4; i++) {
    anm_draw(slot[i * 0x1428]);

    // 每帧（frames & 1 == 0 时跳过）
    if (frames & 1) {
        // 位置 = 基准位置 + 偏移
        pos.x = base_x[i] + offset_x[i];
        pos.y = base_y[i] + offset_y[i];
        // z 也累加
        slot[i].pos = pos;
        slot[i].timer = 0x10;              // 16 帧
    }
}
```

### 6.3 参数

| 参数 | 值 |
|------|-----|
| 总时长 | **140 帧** |
| 槽位 | **4** |
| 更新频率 | **每 2 帧**（`frames & 1`） |
| 位置 | `base + offset`（两者都在累加） |
| 计时 | **16 帧** |
| 第 60 帧 | 播放音效 `0x14` |
| 位置参数 | **`(62, 448)`** 与 **`(384, 62)`** 交替 |

### 6.4 特征

这是**四个对称对象随玩家移动**的 Bomb ——
位置每 2 帧由 `base + offset` 重算，且两者都随时间累加。

**与索引 0 的区别**：索引 0 的弹幕从固定起点线性飞出；
索引 2 的对象是**持续累加位移**（类似环绕/漂移）。

> **实测值**：`62.0` / `448.0` / `384.0`
>
> `448.0` 正是**游戏区高度**（`docs/14`），`384.0` 是**游戏区宽度**。
> 说明这四个对象被放置在**游戏区四角附近**（`(62,448)` 与 `(384,62)` 对角交替）。

## 7. 索引 3（`FUN_0040a3a0`，190 帧，**3 槽**）

### 7.1 这是最简单的 Bomb

只有 61 行，逻辑是**三个连续动画对象跟随玩家**。

### 7.2 初始化

```c
total_frames = 0xbe;         // 190 帧
player_scale = 0xfa;         // 250

// 三个连续 AnmInstance（步长 0x24c）
for (i = 0; i < 3; i++)
    anm_set_sprite_script(&slot[i * 0x24c], i + 0x48d);   // 0x48d, 0x48e, 0x48f

snd_request(6, 0);
set_color(2, 6, 0);

// 记录起始位置
start_x = player->x;
start_y = player->y;
start_z = player->z;

bullet_rank_scale(0.17f);    // 0x3e2e147b
param_1[0x23f4] = 0.4f;      // 0x3ecccccd
param_1[0x23f0] = 0.4f;

// 起始特效
eff_spawn_scaled(player->pos, 192.0, 0.384, 0xd2, 6);
```

### 7.3 每帧

```c
// 绘制三个槽位
anm_draw(slot[0]);
anm_draw(slot[1]);     // +0x24c
anm_draw(slot[2]);     // +0x498

// 位置 = 释放瞬间的玩家位置 + 累计偏移
pos.x = start_x + offset_x;
pos.y = start_y + offset_y;
pos.z = start_z + offset_z;
scale = 256.0;
timer = 0x12;          // 18 帧
```

### 7.4 参数

| 参数 | 值 |
|------|-----|
| 总时长 | **190 帧** |
| 槽位 | **3**（连续 AnmInstance，步长 `0x24c`） |
| 脚本 | `0x48d` / `0x48e` / `0x48f` |
| 位置 | **释放瞬间位置 + 累计偏移** |
| 缩放 | **256.0** |
| 计时 | 18 帧 |
| 起始特效 | 缩放系数 `192.0`，`0.384` |
| 子弹等级缩放 | **0.17** |
| 状态参数 | `0x23f4`/`0x23f0` = **0.4** |
| 结束恢复 | `0x23f4`/`0x23f0` = **1.0** |

**特征：三个跟随玩家的连续特效对象，无弹幕生成。**

## 8. 槽位数汇总（已读 6 个 Bomb）

| 索引 | 槽位 | 结构 |
|------|------|------|
| 0 | **8** | 8 等分星形，固定起点 |
| 1 | **8** | 随机散落，每弹取位置 |
| 2 | **4** | 四角对称对象，base+offset 累加 |
| 3 | **3** | 三连跟随对象，无弹幕 |
| 8 | **96** | 随机迸发 |
| 9 | **96** | 96 等分螺旋 |

**槽位数：3 / 4 / 8 / 96 —— 四种值，无规律。**
**重制版必须为每个 Bomb 单独配置槽位数。**
