# Bomb 几何详解（索引 8 与 9）

> 补全 `docs/44-all-bombs.md` 中索引 8、9 的弹幕几何。
>
> 这两个与索引 0/1 的**结构完全不同** —— 它们用了 96 个槽位。

---

## 1. 槽位数量：一个关键差异

| Bomb | 槽位数 | 更新循环 |
|------|--------|---------|
| 索引 0/1 | **8** | `for (i = 0; i < 8; i++)` |
| **索引 8/9** | **96（0x60）** | `for (i = 0; i < 0x60; i++)` |

**重制版必须按 Bomb 类型分配槽位，不能统一用 8 个。**

---

## 2. 索引 8（`FUN_0040c2e0`，160 帧）

### 2.1 初始化

```c
total_frames = 0xa0;          // 160 帧
player_scale = 0xd2;          // 210

// 记录起始位置
start_x = player->x;
start_y = player->y;
start_z = player->z;

// 清空 96 个槽
for (i = 0; i < 0x60; i++)
    slots[i] = 0;

bullet_rank_scale(0.28f);     // 0x3e8f5c29

// 生成一个追踪载具
carrier = obj_spawn(0x15, player->pos, 1, 0xffffffff);
param_1[0x17e64] = carrier;

snd_request(5, 0);
```

### 2.2 生成（第 60–121 帧）

```c
if (frames > 0x3b) {                          // 第 60 帧后，每帧执行
    budget = 5;                                // ← 每帧重置为 5（已确认）
    for (i = 0; i < 0x60; i++) {
        if (slots[i] == 0) {
            if (frames < 0x79 && budget != 0) {  // 第 121 帧前
                slots[i] = 1;
                anm_set_script(i, (i & 1) + 0x405);   // 交替两种外观

                angle     = rand() * 2π - π;          // 随机方向
                speed     = rand() * 6.0 + 5.5;       // [5.5, 11.5]
                scale     = rand() * 0.1 + 0.1;       // [0.1, 0.2]
                spin      = rand() * 0.0628 - 0.0314; // ±0.0314 rad ≈ ±1.8°

                vx = cos(rand*2π) * 24;               // 初速分量
                ...
                budget--;
            }
        }
    }
}
```

### 2.3 参数汇总

| 参数 | 值 |
|------|-----|
| 总时长 | **160 帧** |
| 生成窗口 | **第 60–121 帧** |
| 每帧上限 | **5 个** |
| 槽位 | **96** |
| 角度 | **随机** `rand*2π - π` |
| 速度 | **`rand*6 + 5.5`** → [5.5, 11.5] |
| 缩放 | `rand*0.1 + 0.1` → [0.1, 0.2] |
| 自旋 | `rand*0.0628 - 0.0314` → ±1.8°/帧 |
| 外观 | `(index & 1) + 0x405`（**两种交替**） |

**特征：从随机方向迸发的密集弹幕。**

**生成速率**：第 60–121 帧共 61 帧 × 每帧最多 5 个 = **理论上限 305 个**，
但受 **96 个槽位**限制，所以实际最多 **96 个**（槽满即停）。

## 3. 索引 9（`FUN_0040ca50`，250 帧）

### 3.1 初始化

```c
total_frames = 0xfa;          // 250 帧
player_scale = 0x122;         // 290

// 96 个槽清零
bullet_rank_scale(0.29f);     // 0x3e947ae1
param_1[0x23f4] = 0.3f;       // 0x3e99999a
param_1[0x23f0] = 0.3f;

carrier = obj_spawn(0x15, player->pos, 1, 0xffffffff);
param_1[0x17e64] = carrier;

snd_request(5, 0);
```

### 3.2 载具跟随（第 0–60 帧）

```c
if (frames >= 0 && frames < 0x3d) {
    carrier->pos = player->pos;      // 载具紧跟玩家
}
```

**载具在前 60 帧跟随玩家。**

### 3.3 生成（第 20–115 帧）

```c
if (frames > 0x13 && frames < 0x74) {         // 第 20–115 帧
    for (i = 0; i < 0x60; i++) {              // 96 个槽
        // 每个槽在特定帧生成
        if (frames == (i % 0x30) * 2 + 0x14) {
            slots[i] = 1;
            anm_set_script(i, (i & 1) + 0x407);      // 两种交替

            // ← 角度：96 等分，从 -π 起
            angle = (i * 2π) / 96.0 - π;

            speed = rand() * 1.0 + 0.5;              // [0.5, 1.5]
            scale = rand() * 0.1 + 0.03;             // [0.03, 0.13]

            spin  = -0.1571;                         // ← -9°/帧，固定

            vx = cos(rand*2π) * 24;                  // 附加初速
            vy = sin(rand*2π) * 24;

            // 位置 = 玩家位置 + 初始偏移
            pos.x = player->x + vx;
            pos.y = player->y + vy;
            pos.z = 0;
        }
    }
}
```

### 3.4 参数汇总

| 参数 | 值 |
|------|-----|
| 总时长 | **250 帧** |
| 生成窗口 | **第 20–115 帧** |
| 生成节奏 | 每个槽在 `(i % 48) * 2 + 20` 帧 |
| 槽位 | **96** |
| 角度 | **`(i * 2π) / 96 - π`**（96 等分） |
| 速度 | **`rand + 0.5`** → [0.5, 1.5] |
| 缩放 | `rand*0.1 + 0.03` → [0.03, 0.13] |
| 自旋 | **−0.1571 rad = −9°/帧**（固定） |
| 载具跟随 | 前 60 帧 |

**特征：围绕玩家螺旋扩散的弹幕。**

### 3.5 角度遍历

| index | 角度 |
|-------|------|
| 0 | **−180°** |
| 1 | −176.25° |
| 24 | −90°（正上） |
| 48 | **0°**（正右） |
| 72 | 90°（正下） |
| 95 | **176.25°** |

**96 个槽覆盖完整 360°，每个间隔 3.75°。**

## 4. 三种 Bomb 结构对照

| 特征 | 索引 0 | 索引 1 | 索引 8 | 索引 9 |
|------|--------|--------|--------|--------|
| 槽位 | 8 | 8 | **96** | **96** |
| 角度 | 8 等分固定 | 随机 | 随机 | **96 等分** |
| 速度 | 固定 15 | 固定 8 | rand[5.5,11.5] | rand[0.5,1.5] |
| 起始位置 | 释放瞬间 | 每弹生成时 | 玩家位置 | **玩家位置+随机** |
| 外形 | 星形 | 散落 | 迸发 | 螺旋 |

**每个 Bomb 的"手感"由这四项共同决定，缺一不可。**
