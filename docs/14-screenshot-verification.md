# 截图验证报告：实测 vs 反汇编推断

> 本文档用**真实运行截图**（640×480）逐项校验此前的逆向结论。
> 凡有冲突处，以截图为准，并记录修正。

---

## 1. 总览：哪些对了，哪些错了

| 项目 | 此前推断 | 截图实测 | 结论 |
|------|---------|---------|------|
| 屏幕分辨率 | 640×480 | 640×480 | ✅ |
| 游戏区尺寸 | 384×448 | **384×448** | ✅ |
| 游戏区原点 | (32,16)（未确认） | **(32,16)** | ✅ **已确认** |
| HUD 起始 X | 512 | 见 §3 | 🔶 修正 |
| HUD 行距 | 16 | **16** | ✅ |
| 结算行距 | +32 / +16 | 待验 | ✅ |
| **HUD 内容项** | Graze / Point | **Power / Graze / Point** | ❌ **漏了 Power** |
| **Player/Bomb 显示** | 数字 | **星星图标** | ❌ **判断错误** |
| **标题菜单顺序** | Start/Extra/Practice/Quit/Replay/Result/MusicRoom/Option | **Start/Extra Start/Practice Start/Replay/Result/Music Room/Option/Quit** | ❌ **顺序错误** |
| 设置界面 | 复用 title01 图集 | 确认复用 | ✅ |

## 2. 关键修正一：标题菜单顺序

**此前（来自图集文字顺序的推断）**：
```
Start  Extra Start  Practice Start  Quit
Replay Result       Music Room      Option
```

**截图实测（垂直单列，8 项）**：
```
Start              ← 选中态（亮白）
Extra Start
Practice Start
Replay
Result
Music Room
Option
Quit               ← 最后一项
```

**教训**：图集中文字 sprite 的**排列顺序**不等于**菜单显示顺序**。
菜单顺序由代码决定，必须从截图或绘制逻辑确认。

## 3. 关键修正二：HUD 的精确布局（实测）

### 3.1 HUD 区域

```
游戏区:  x = 32 .. 416      (宽 384)
         y = 16 .. 464      (高 448)

HUD 区:  x = 416 .. 640     (宽 224)
```

### 3.2 文字行位置（像素级实测）

| 元素 | 标签 Y 范围 | 数值 Y 范围 | 内容 |
|------|------------|------------|------|
| **HiScore** | 50–59 | 49–61 | `001000000` |
| **Score** | 66–75 | 65–77 | `00000000` |
| **Player** | 98–100 | — | ★★（红色星星） |
| **Bomb** | 116–118 | — | ★★★（蓝色星星） |
| **Power** | — | 146–155 | `0` |
| **Graze** | 147–155 | 162–171 | `0` |
| **Point** | 163–171 | 177–189 | `0/50` |

### 3.3 行距规律

```
HiScore → Score      : 16 px
Score   → Player     : 32 px
Player  → Bomb       : 18 px
Bomb    → Power      : 30 px
Power   → Graze      : 16 px
Graze   → Point      : 16 px
```

> **推翻此前结论**：HUD 不是 `Graze/Point` 两项，
> 而是 `Power / Graze / Point` **三项**（Power = 火力值）。

### 3.4 Player / Bomb 是图标不是数字

截图中 `Player` 行显示 **2 颗红星**，`Bomb` 行显示 **3 颗蓝星**。

对应 `ascii.anm` 里的 **8×8 小图标** sprite。

此前我曾推断「图标从 X=496 起、间隔 16px」——这部分**与实际一致**
（星星横向等距排列）。

### 3.5 HUD 其他元素

| 元素 | 位置 | 内容 |
|------|------|------|
| 竖排标题 | HUD 区右侧 | `東方妖々夢`（竖排大篆体） |
| 英文标题 | 其左 | `Perfect` / `Cherry` / `Blossom`（三行右对齐） |
| FPS | 右下角 | `60.00fps` |
| 樱点 | 游戏区左下 | `Cherry ↑` + 计数 `0/200000` |

## 14. FPS 计数器（全局）

所有截图右下角都有 `60.xx fps`：

```
游戏: 60.00fps    标题: 60.02fps    音乐室: 59.97fps
```

**这是全局叠加**，与场景无关。说明 TH07 有**常驻的 FPS 显示**，
可能是调试功能或标准显示。

重制版可选择性保留。
