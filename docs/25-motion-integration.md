# 运动积分模型（精读）

> 来源：`obj_integrate_motion`（`FUN_0041a4f0`）与关联的阻尼代码。

---

## 1. 字段布局

| 偏移 | 含义 |
|------|------|
| `+0x24c` `+0x250` `+0x254` | **位置** X / Y / Z |
| `+0x264` `+0x268` `+0x26c` | **速度** X / Y / Z |
| `+0x270` `+0x274` `+0x278` | **加速度** X / Y / Z |

---

## 2. 每帧积分（obj_integrate_motion）

```c
void obj_integrate_motion(obj)
{
    // 1. 位置 += 速度
    obj->pos.x += obj->vel.x;
    obj->pos.y += obj->vel.y;
    obj->pos.z += obj->vel.z;

    // 2. 速度 += 加速度
    obj->vel.x += obj->acc.x;
    obj->vel.y += obj->acc.y;
    obj->vel.z += obj->acc.z;
}
```

**这是标准的半隐式欧拉积分**（semi-implicit Euler）：
先更新位置（用旧速度），再更新速度。

> 与显式欧拉的区别：半隐式在能量守恒上更稳定，
> 是游戏物理的常见选择。

## 3. 阻尼模型

在另一处（`0x350a` 附近）：

```c
obj->acc.x = -obj->vel.x * 0.05263158f;    // = -vel / 19
obj->acc.y = -obj->vel.y * 0.05263158f;
obj->acc.z = -obj->vel.z * 0.05263158f;

obj->acc.x *= g_slow_factor;
obj->acc.y *= fVar1;
obj->acc.z *= fVar1;
```

### 3.1 系数来源

```
0.05263158 = 1 / 19
```

**加速度与速度成正比且反向** —— 这是**线性阻尼（空气阻力）**。

每帧速度衰减：

```
v_next = v + (-v/19) = v * (1 - 1/19) = v * (18/19)
```

即**每帧保留 94.7%** 的速度。

### 3.2 半衰期

```
v(t) = v0 * (18/19)^t
半衰期: (18/19)^t = 0.5
     t = ln(0.5) / ln(18/19) ≈ 12.82 帧
```

**实测验算**：每帧保留 `0.947368`，半衰期 **12.82 帧 ≈ 0.214 秒**（@60fps）。

### 3.3 重制版照抄

```lua
-- 每帧
local DAMPING = 1 / 19
obj.acc_x = -obj.vel_x * DAMPING
obj.vel_x = obj.vel_x + obj.acc_x
obj.pos_x = obj.pos_x + obj.vel_x
```

**注意**：TH07 用的是「先位置后速度」的更新顺序（见 §2），
照抄时要保持这个顺序。

---

## 4. 与时间缩放的交互

```c
obj->acc *= g_slow_factor;
```

`g_slow_factor`（`DAT_00575ac8`）是**全局慢放倍率**：

| 场景 | 值 |
|------|-----|
| 正常 | 1.0 |
| 慢放（Boss 死亡、符卡背景） | < 1.0 |

**注意**：阻尼计算的是加速度，所以慢放会同时影响位置和速度的推进速率。

---

## 5. 应用场景

这套积分模型用于：

- **子弹轨迹**（加速度 + 阻尼 = 曲线弹道）
- **敌人移动**（惯性运动）
- **掉落物 / 特效**

ECL 中的「设置速度 / 加速度」指令最终都写入这三个字段。
