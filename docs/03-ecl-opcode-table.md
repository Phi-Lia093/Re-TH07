### 5.1 运动模式位（`+0x2e28`）

```
bit0-1: 0 = 无运动   1 = 直接速度   2 = 插值运动
bit2-4: 缓动曲线类型 (0=线性, 1=t², 2=t³, 3=t⁴, 4=easeOut2, 5=easeOut3, 6=easeOut4)
bit5:   1 = 冻结（暂停本实例）
```

缓动曲线在解释器里已确认（`FUN_00410520` 第 9372–9412 行）：
```c
case 1: e = e*e;        case 2: e = e*e*e;      case 3: e = e*e*e*e;
case 4: e = 1-(1-e)²;   case 5: e = 1-(1-e)³;   case 6: e = 1-(1-e)⁴;
```

### 6.1 `ins_64 ~ ins_72`：9 种子弹发射器

**同一个实现**，用 `id - 0x40` 区分（写入 `local_20[0x60]`）。已完整解码：

```c
参数（按 mask 位）：
  slot3 (bit0, i) : 弹种/形状 ID
  slot4 (bit1, i) : 数量 = 2
  slot5 (bit2, i) : 扩散角度 ↑ (local_20[0x5e])
  slot6 (bit3, i) : 扩散角度 ↓ (local_20[0x5f])
  slot7 (bit4, f) : 角度
  slot8 (bit5, f) : 速度
  slot9 (bit6, f) : 加速度? (local_20[8])
  slot10(bit7, f) : 速度? (local_20[10])

位置 = 自身位置 + 偏移(+0x2b74/78/7c)
难度修正：数量/角度按 DAT_0062f8a4（难度 0..3）插值
加速度 < 0.3 时钳制为 0.1（0x3e99 = 0.3f 的近似位模式）
```

`FUN_00424d20` = 弹幕生成器：`for 行 × 列 → FUN_00423730(创建子弹)`，上限 0x400 发。

**用真实数据验证**（`ecldata` 中 op64–72 的实际字节）：

```

op66 mask=0x0000 size=44  [393221,10, 1, 1.5f, 1.0f, 0, 0,     517]
```

5. 保留 `tools/opcode_effects.py` 的输出作为**回归基线**：
   任何语义修订都应能 diff 出变化
