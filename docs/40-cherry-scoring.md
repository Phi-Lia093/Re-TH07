# 樱点（Cherry）计分机制

> 来源：HUD 绘制、结算、录像加载等多处。
> **补上了 FINAL-STATUS 中「樱点计分方式」的空白。**

---

## 1. 字段

| 全局 | 含义 | 证据 |
|------|------|------|
| **`DAT_0062f888`** | **樱点上限**（本关设置，**游戏中不增长**） | 只在录像加载时赋值 |
| **`DAT_0062f88c`** | **樱点当前值**（**会减少，不增长**） | 多处扣减，无增长 |
| `DAT_00626278[0x22]` | **关卡起始基准** | 用于计算相对值 |

> **重要**：`f888` 在整个游戏中**只被赋值一次**（录像加载时从存档恢复）。
> 它是**该关的樱点上限常量**，不是累积增长的。
>
> `f88c`（当前值）有多种**扣减**：死亡、清屏等，但**没有增长点**。
>
> 这说明樱点是**「可消耗的护盾」**而非「累积的分数」。

### 1.1 显示的派生值

```c
cherry_display = f888 - base;      // 上限的相对值（HUD 第一行）
current_rel    = f88c - base;      // 当前的相对值（HUD 第二行）
```

结算时：

```c
"Cherry = %8d"(+0x20a28 * 10)
  其中 +0x20a28 = f888 - base
```

**注意 ×10** —— 与其他计分项一致（分数以 1/10 为单位）。

## 2. HUD 显示规则

```c
if (f88c < f888) {                    // 未满
    if (current_rel < 50000)
        颜色 = 白色 (0xffffff)
    else
        颜色 = 半透明白 (0x80ffff)
} else {                              // 已满
    颜色 = 淡紫黄 (0x80d0ff)
}
```

**颜色表示「樱点是否已满」**。

### 2.1 数值行的绘制

```c
// 第一行：当前值
value = f88c - base;
for (i = 0; i < 6; i++) {
    digit = value / divisor;
    value = value % divisor;
    if (digit != 0 || divisor == 1 || already_started) {
        anm_bind_sprite(slot, digit + 0x84);
        anm_draw(slot);
        already_started = true;
    }
    x += 7.0;                         // 每字 7 像素
    divisor /= 10;
}
```

**6 位数字，前导零跳过，字距 7 像素。**

## 3. 上限的来源

`f888` 在录像加载时恢复：

```c
f888 = replay->max_cherry + base;     // 31420 行
```

**说明「樱点上限」是本关可能达到的最大值**，
而不是固定常数 —— 它会随游戏的进程而增长。

### 3.1 扣减机制（**已解出**）

樱点当前值 `f88c` 只有扣减。已知的扣减点：

| 触发 | 扣除量 | 位置 |
|------|--------|------|
| **死亡** | **200 单位**（= 2×100） | `FUN_00442dd0` 链 |
| **死亡** | **50%**（`.sht+0x1C`） | 百分比扣除 |
| **清屏（kind=10）** | **`rand()` 取整到 10** | `0x3e6c` 附近 |
| **复活后** | `+0x16a2c`（难度相关） | 死亡结算 |

### 3.2 清屏扣樱点（新发现）

```c
// 0x3e6c 附近
FUN_00424740(10);                     // 清屏，kind = 10
iVar1 = rand();
f88c -= (iVar1 - iVar1 % 10);         // ← 随机扣除，取整到 10
```

**`kind=10` 的清屏会扣除随机樱点。**

这是我之前把 `bullet_clear_all(10)` 当作"清除某类对象"时的遗漏 ——
它**同时扣减樱点**。

## 4. 结算公式

```
Cherry 得分 = (f888 - base) * 10
```

即**本关达到的樱点相对值 × 10**。

与其他项对比（见 `docs/33`）：

| 项目 | 公式 |
|------|------|
| Clear | `stage × 1,000,000` |
| Point | `point × 50,000` |
| Graze | `graze × 500` |
| **Cherry** | **`(上限 - 基准) × 10`** |
