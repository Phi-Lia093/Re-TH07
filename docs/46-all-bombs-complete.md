## 2. 各 Bomb 的实现要点

### 2.1 索引 0（星形）

```
第 8–79 帧，每 6 帧生成（index 0–11，但只更新 8 个）
角度 = index * 2π/8 - π/2
起始位置 = 释放瞬间（所有弹共享）
速度 15.0，减速 0.4/帧，< -10.0 爆开
x ≥ 192 时镜像
```

### 2.2 索引 1（散落）

```
第 60–179 帧，每 16 帧生成（index 0–7）
角度 = rand()*2π - π
起始位置 = 每弹生成时的玩家位置
速度 8.0
```

### 2.3 索引 2（四角对称）

```
4 个对象交替在 (62, 448) 与 (384, 62)
每 2 帧：pos = base + offset（两者累加）
计时 16 帧
```

### 2.4 索引 3（跟随）

```
3 个连续 AnmInstance（0x24c 步长），脚本 0x48d/0x48e/0x48f
位置 = 释放瞬间 + 累计偏移
缩放 256.0，计时 18 帧
无弹幕生成
```

### 2.5 索引 4（加速扩散）

```
第 0 帧初始化 8 个，角度 = index * 2π/8（从 0° 起）
初速 2.0，加速度 96.0
每 3 帧绘制一次
外观 index % 3 + 0x405
```

### 2.6 索引 5（拖尾散射）

```
每 6 帧生成（最多 24 个）
角度 = rand*2π/16 - 2π/32 - π/2   → -90° ± 11.25°
初速 -5.0（负！）
每个弹 8 段拖尾
```

### 2.7 索引 6（环状环绕）

```
6 个粒子围绕玩家
角度 = frames * π/30 / total_frames     （绕圈）
半径 = 基础尺寸 * 缩放 / 5 递增
每 6 个粒子一组
第 20 帧、第 80 帧触发音效
```

### 2.8 索引 7（水平光波）

```
4 个槽，脚本 0x408..0x40b
位置固定在 (384, player.y)   ← 游戏区右边缘
每 4 帧重绘
第 60 帧、第 120 帧触发音效
```

### 2.9 索引 8（迸发）

```
第 60–121 帧，每帧最多 5 个
96 个槽
角度随机，速度 rand*6+5.5
外观 (i & 1) + 0x405
```

### 2.10 索引 9（螺旋）

```
第 20–115 帧
角度 = (i * 2π) / 96 - π        （96 等分，3.75° 步进）
速度 rand + 0.5
自旋 -9°/帧（固定）
载具前 60 帧跟随玩家
```

### 2.11 索引 10（十字汇聚）

```
4 个槽，脚本 0x409..0x40c
位置 = (±128 + 192, ±128 + 192) → (64 或 320, 64 或 320)
即四个象限的对称点
第 30、60、120 帧触发
```

### 2.12 索引 11（超长拖尾）

```
2 个槽，脚本 0x40d..0x40e
每个弹 32 段拖尾（0x1f..0）
加速度 -0.008（0xbc03126f）
缩放 160.0
第 40 帧触发音效
```

## 3. 位置正确性检查清单（**所有 Bomb 通用**）

```lua
-- 1. 屏幕偏移必须加
pos.x = pos.x + 32      -- g_screen_offset_x
pos.y = pos.y + 16      -- g_screen_offset_y

-- 2. z 必须归零
pos.z = 0

-- 3. 时间缩放
vel = vel + acc * g_slow_factor

-- 4. 槽位数按 Bomb 类型
slots = BOMB_SLOT_COUNT[bomb_index]
```

**漏掉任何一项都会导致错位或被遮挡。**

## 4. 常见实现错误

| 错误 | 后果 | 涉及 Bomb |
|------|------|----------|
| 统一用 8 槽 | 丢了 88 个弹 | 8, 9 |
| 起始位置跟随玩家 | 星形变糊 | 0, 3, 4 |
| 初速取正 | 运动方向反了 | **5**（-5.0） |
| 忘记镜像 | 左右不对称 | 0 |
| 漏屏幕偏移 | 整体偏 (32,16) | **全部** |
| z 不归零 | 被背景遮挡 | **全部** |
| 忽略 `% 3`/`% 4` 绘制间隔 | 特效过密 | 4, 7 |
